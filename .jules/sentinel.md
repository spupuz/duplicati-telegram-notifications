## 2026-09-02 - Symlink Vulnerability in Cache File Redirection
**Vulnerability:** Symlink (CWE-59) or Arbitrary File Overwrite vulnerability when using direct output redirection (`>`) to write the script version to a predictable cache file inside a potentially shared directory (like `/tmp` or `$XDG_CACHE_HOME`).
**Learning:** Redirecting output directly to a predictable file path (`> "$cache_file"`) is extremely dangerous if the destination directory is world-writable or shared. An attacker can create a symlink with that predictable name pointing to a critical file (like `/etc/passwd`), causing the script to blindly overwrite the target file's content or change permissions when run by a privileged user.
**Prevention:** To prevent file overwrite attacks through symlinks, never redirect output (`>`) directly to a predictable file in a shared directory. Instead, securely create a temporary file using `mktemp`, write the data there, and then use `mv -f` to atomically move it to the target location. `mv` replaces symlinks rather than following them.
