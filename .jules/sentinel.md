## 2024-05-24 - [Insecure TLS Configuration]
**Vulnerability:** The Telegram notification curl command used the `-k` (`--insecure`) flag, bypassing TLS certificate verification (`curl -s "$TELEGRAM_URL" ... -k`).
**Learning:** This exposed the request to Man-in-the-Middle (MitM) attacks, allowing interception of the bot token in the URL and the backup metadata in the request body. Skipping TLS validation completely undermined the confidentiality and integrity of the API request to Telegram.
**Prevention:** Never use `--insecure` or `-k` flag with `curl` for production API calls. Rely on the system's CA certificates to properly validate the server's identity to prevent interception of sensitive secrets (like API tokens) and payload data.
